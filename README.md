# Домашняя работа к лабораторной номер 4

## Задача

Реализовать систему контроля доступа в умный коворкинг.  
Есть два сканера: по лицу (код `A`) и по карте (код `B`).  
Дверь открывается, **если ровно один из кодов — чётный** (временные посетители).

## Алгоритм

1. Инициализировать переменные `A`, `B`, `vhod`.
2. Вывести приглашение к вводу.
3. Считать два целых числа `A` и `B`.
4. Вычислить условие: `(A % 2 + B % 2) == 1`.
   - `A % 2` и `B % 2` дают остатки: `0` для чётных, `1` для нечётных.
   - Сумма остатков равна `1` только когда один код чётный, а другой нечётный.
5. Присвоить результат переменной `vhod` (`1` — доступ разрешён, `0` — запрещён).
6. Вывести результат.

## Код (C)

```c
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    int A, B;
    int vhod;

    printf("ДОСТУП В КОВОРКИНГ\n");
    printf("Введите код со сканера лица (A) и код с карты (B): ");
    scanf_s("%d %d", &A, &B);

    vhod = ((A % 2 + B % 2) == 1);

    printf("Доступ разрешён (1 - да, 0 - нет): %d\n", vhod);

    return 0;
}
